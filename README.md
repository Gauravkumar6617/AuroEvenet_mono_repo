# BlogByte_mono_repo
# 📝 BlogByte

A modern full-stack blog platform built with **FastAPI (Python)** and **React**, using a **monorepo architecture** and modern tooling like **uv (Python package manager)** and **pnpm (Node package manager)**.

---

## 🚀 Tech Stack

### ⚙️ Backend (FastAPI)
- FastAPI
- SQLAlchemy
- PostgreSQL (planned)
- Redis (cache & sessions)
- JWT Authentication (planned)
- OAuth (Google/GitHub) (planned)
- **uv (Python dependency manager)**

### 🌐 Frontend
- React (planned)
- Tailwind CSS
- pnpm (fast Node package manager)

### 🏗️ Infrastructure
- Monorepo architecture
- Docker (planned)
- CI/CD (planned)

---
