# 🚀 AI Blog Application

An AI-powered blog platform built with **FastAPI (backend)** and a modern frontend.  
The system allows users to create, manage, and interact with blog content, with intelligent features powered by AI.

---

## ✨ Features

- 📝 Create, update, delete blog posts
- 🤖 AI-assisted content generation (optional integration)
- 📩 Contact form with email notifications
- 🔐 Authentication system (JWT-based)
- 👤 User profile management
- 📊 Clean API architecture with FastAPI
- ⚡ High-performance async backend
- 🎯 Modular and scalable code structure

---

## 🛠️ Tech Stack

### Backend

- FastAPI
- SQLAlchemy
- Pydantic v2
- Alembic (migrations)
- PostgreSQL / MySQL (configurable)
- SMTP Email Service

### Frontend

- React (Vite)
- TypeScript / JavaScript
- TailwindCSS (or your styling system)
- Custom Toast System / React Context
